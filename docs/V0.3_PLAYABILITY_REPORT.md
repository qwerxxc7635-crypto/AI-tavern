## 7. 性能、Context 与 Cache

### 性能

- 三世界固定长测：7815.667 ms / 96 行为，行为加权摊销 81.413 ms。
- Fantasy / Investigation / Cyberpunk 分别为 71.835 / 80.566 / 91.839 ms/行为。
- 自由输入压力：2291.522 ms / 8 行为，摊销 286.44 ms/行为；包含跨三个已存在数据库的多次打开、事务、重开和 archive 导出，不能与单世界固定流直接比较。
- 上述均为本地 production transaction wall time，不是模型推理或 Provider billing latency，也不替代 [`V0.3_PERFORMANCE_REGRESSION.md`](V0.3_PERFORMANCE_REGRESSION.md) 的 M10 性能门。

### Context

M11 summary 的最大持久 context bytes 为 Fantasy 48、Investigation 0、Cyberpunk 0。后两个 `0` 只说明对应运行未留下可计量的 context payload；NPC knowledge、conversation 和 scene 的数据库证据仍证明生产上下文边界被使用。容量与长期增长继续由 M10 的 Unified Context ≤2048 tokens、增长 ≤1.05× 门约束。M11 没有把 `0 bytes` 夸大为“零 Context 成本”。

### Cache

M11 的 Fake Provider 没有报告 token 或 Provider 计费 cache usage，因此 V0.3 M11 的 input/output tokens、cache hit、cache miss 和 billing hit ratio 全部为 `NOT_EVALUATED`。本地稳定前缀复用也不被当作 Provider 计费命中。缓存发布判断必须在 M12 引用 M10 权威门，并对任何真实 Provider 证据单独标注来源。

## 8. Remaining Risks

- V0.3 尚无真实 Provider 的 20+ 回合长测，无法证明真实叙事、NPC 声线、人格漂移和开放输入泛化达到 8.8 分。
- M11 使用确定性合成场景和 Fake 输出；它强力证明事务与合同，但不能覆盖真实模型的非法 JSON、语义偏离、网络抖动和费用风险。
- Investigation/Cyberpunk 的 `maxContextBytes=0` 是观测稀疏，不是上下文不存在；M12 必须把 M10 Context/Cache 证据与 M11 行为证据联合复核。
- 每世界 32 个行为达到规格的 30～50 范围，但仍是单一合成 Campaign；更长存档和更多世界种子可能暴露新的 Director、Quest 或经济漂移。
- `M11-FAN-001` 已修复，但证明长测曾捕获真实 P1；M12 必须从当前源码重新审计，不能仅采信 `FIXED` 标签。
- Windows 实机安装生命周期、跨平台 release 产物、安全与完整视觉复核属于 M12 范围，本报告不提前给出结论。
