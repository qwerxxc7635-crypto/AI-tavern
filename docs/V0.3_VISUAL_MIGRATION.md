# Ember Tavern V0.3 视觉迁移与债务清单

状态：进行中

全局规范：`docs/EMBER_TAVERN_VISUAL_STYLE_GUIDE_V1.md`

最终收敛任务：`M10-T07 Visual System Convergence`

## 1. 目的与边界

本清单把 V0.3 前半段已经完成的 UI 与视觉手册之间的差异登记为视觉债务，避免在 M4-T03 或其他业务任务中逐页返工。视觉债务不代表现有页面功能失败；迁移不得改变业务语义、状态机、数据合同、SQLite 事实、存档兼容性或 AI/Rules 权限边界。

从本文件落地起，新增 UI 和当前任务自然需要修改到的 UI 在不明显扩大任务范围时直接遵循视觉手册。超出当前边界的调整只登记，不提前实施。

## 2. 已有基础（复用，不重建）

- M2-T01 已建立 Primitive / Semantic / Component 三层 CSS Token 与兼容别名。
- M2-T02 已建立 14 类 UI Primitives，包含键盘、焦点、reduced-motion 和 forced-colors 合同。
- M2-T03～T05 已建立共享 Game Components、AIFieldAssist 与 ActionComposer 的展示/状态机边界。
- `CharacterCard`、`NpcCard`、`QuestCard`、`TraitCard`、`ItemCard`、`DialogueView`、`GenerationPanel`、`StatusPanel`、`AIFieldAssist` 与 `ActionComposer` 是后续迁移基础，不创建视觉平行实现。

## 3. 当前视觉债务基线（2026-08-14）

- `windows-app/src/design-tokens.css` 是允许保存原始视觉值的 Token 源；`windows-app/src/theme.css` 仍有 41 处 raw color/rgba 值，分布在 Archive、App Shell、Save、World、Character、Tavern、NPC、Quest、Adventure、D20、Settings、Recovery 等历史页面样式，需迁移为语义/组件 Token。
- 历史页面已经具备可运行布局与部分共享组件迁移，但尚未逐页按视觉手册核对 Typography、Color、Spacing、Radius、Border、Shadow、Motion 和信息层级。
- 酒馆、对话、冒险、D20、车卡、Trait、Quest、Loading/Streaming、Toast/Empty/Error、Provider 状态需要在功能最终成形后统一核对“游戏世界优先、AI 身份后置”的表达。
- 当前唯一 TSX inline style 是 NPC 关系进度的动态宽度，属于运行时几何值而非视觉常量；仍需在最终审查确认其可访问名称和非颜色状态表达。
- M0～M4-T02 已完成页面不在 M4-T03 期间返工，除非 M4-T03 自然新增极小 UI 且无需扩大业务范围。

## 4. 渐进迁移顺序

1. **Design Tokens**：补全并冻结字体、色彩、间距、Border、Radius、Shadow、Motion 的语义 Token，建立 raw-value 静态门。
2. **UI Primitives**：只扩展现有 primitives 缺失状态，不创建第二套 Button/Card/Overlay/Form。
3. **Game Components**：在现有合同上收敛 Character/NPC/Quest/Trait/D20/Narrative/Adventure 等视觉与状态表达。
4. **Feature Pages**：M5～M10 新功能在实现时迁移自然触及页面并保留可运行门禁。
5. **Legacy UI Migration**：M10-T07 迁移仍使用兼容别名或 raw visual value 的历史页面。
6. **Visual Consistency Audit**：M10-T07 完成逐页、逐状态、逐视口证据；M12-T01 独立复核并由 M12-T02 修复发现。

## 5. 完成定义

- 非 Token 源不再重复硬编码近似视觉常量；例外必须有可复核理由。
- 页面仅复用一套 primitives 与 game components，视觉调整不改变已通过测试的业务行为。
- 主方向为黑暗奇幻酒馆 × TRPG 冒险手册 × 现代桌面游戏 HUD；不出现 ChatGPT Clone、SaaS Dashboard、廉价页游奇幻、巨大圆角或 AI 品牌泛滥。
- 四个既定桌面视口、WCAG AA、键盘焦点、非颜色状态、reduced-motion、可跳过 D20 动画均有证据。
- 所有未关闭差异都进入 M12 findings ledger，不静默忽略。
