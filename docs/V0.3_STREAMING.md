# V0.3 Streaming 与提交边界

本文是 `M10-T03` 的实现约束，补充 [`V0.3_SPEC.md`](V0.3_SPEC.md) 与 [`TASKS.md`](TASKS.md)。Streaming 只改善等待体验，不改变 SQLite、Generator、NPC、World 或 Provider 的事实权限。

## 能力与回退

- `AIProvider.generate` 仍是必需合同；`generateStream` 是可选能力。
- 只有保存的 Model capability 明确声明 `streaming` 且 Provider 实现可选接口时才走流式路径；其他 Provider 原样使用完整响应路径。
- DeepSeek、Qwen、OpenRouter 与 Ollama 的新连接探测记录 OpenAI-compatible streaming 能力；旧配置可继续非流式运行，重新探测后才能启用流式 UX。
- Primary 已输出任何 chunk 后不得切换 fallback，以免把两个模型的正文拼接；未输出 chunk 的既有 fallback 规则保持不变。

## 原生传输

Windows 使用 Tauri v2 `Channel`，不建立第二套全局事件总线：

1. Rust Native 用有界 registry 将 `requestId` 绑定到 `CancellationToken`，并覆盖取消早于 command 注册的竞态。
2. OpenAI-compatible Provider 发送 `stream: true`，通过既有 secure HTTP overall deadline / byte limit / cancellation 读取 SSE。
3. SSE decoder 在 byte 层累计完整 frame，因此 UTF-8 code point、JSON 与 SSE frame 都允许跨网络 chunk；畸形 JSON、缺失 `[DONE]`、模型漂移或额外非空尾部 fail closed。
4. Native 只发送连续 `sequence` 与原始 content delta；最终 command 仍返回一个完整 `NormalizedAIResponse`。
5. TypeScript 重新验证 request identity、连续序号、总大小及“所有 chunk 拼接值 === final content”。

## 结构化输出与玩家可见文本

模型仍返回既有结构化 JSON。原始 JSON chunk 不直接展示：

- NPC 对话只投影顶层 `reply` 字符串。
- 初始世界介绍只投影顶层 `summary` 字符串。
- projector 只产生单调前缀，正确处理跨 chunk escape、Unicode escape 与 surrogate pair；嵌套同名字段不会冒充顶层字段。
- 完整 JSON 仍必须经过现有 task schema、业务规则、重复检测与 native commit 验证。Repair 不流式展示，避免用失败草稿污染已展示前缀。

## 提交、取消与重开

- Chunk 仅存在于组件内存和 Tauri Channel，不写 World、Message、Generation 或其他 SQLite 事实表。
- NPC 在发送前沿用 durable timeline `PENDING`；取消、超时、流顺序错误、final mismatch 与验证错误记录为可恢复失败，绝不插入 Player/NPC 正式消息。
- NPC commit 继续在原事务一次写入完整 Player/NPC 消息、Generation 与 timeline `COMMITTED`；响应丢失后仍以 SQLite `COMMITTED` 为准，避免二次提交。
- 重开投影继续区分 `PENDING`、`FAILED_RETRYABLE` 与已提交消息；已提交 timeline 不显示为待恢复任务。
- 世界介绍只在完整 World schema 验证后调用既有 `world_generation_commit`；取消不会产生半个 World Bible。

## UX 与视觉边界

- NPC 复用 `ActionComposer` 已有 streaming output、Loading 和 Cancel 状态；世界介绍复用同一 stream output 样式与现有按钮体系。
- 新状态遵循 [`EMBER_TAVERN_VISUAL_STYLE_GUIDE_V1.md`](EMBER_TAVERN_VISUAL_STYLE_GUIDE_V1.md)，没有新增硬编码颜色、圆角、阴影或第二套组件体系。
- M10-T03 不逐页返工 Legacy UI；Design Token → UI Primitive → Game Component → Feature Page → Legacy → Audit 的完整收敛仍由 `M10-T07` 执行。

## 验收矩阵

| 风险 | 门禁 |
| --- | --- |
| chunk order / identity | Native sequence + shared orchestrator sequence validation |
| Unicode 边界 | byte-level SSE decoder + structured string projector tests |
| cancel race | pre-dispatch tombstone + active cancellation token tests |
| overall timeout | shared secure HTTP stream deadline tests |
| malformed / missing final | `[DONE]`、SSE JSON、final equality 与 schema tests |
| retry / reopen | durable NPC timeline retry 与 response-loss recovery tests |
| partial commit | NPC 与 World gateway commit-count tests |
| non-stream Provider | optional capability fallback contract test |

## 明确不做

- 不逐 chunk 修改 SQLite 世界状态。
- 不把 Streaming 设为 Provider 必需能力。
- 不改变 Rules Engine、D20、World Constitution、Quest/NPC/Adventure 的业务语义。
- 不在本任务持久化原始 chunk、Prompt 或流式草稿。
- 不提前进入 M10-T04 Cache Optimization 或 M10-T07 全量视觉迁移。
