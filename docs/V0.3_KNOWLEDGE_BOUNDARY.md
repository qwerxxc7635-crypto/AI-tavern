# V0.3 Knowledge Boundary

本文固定 M4-T04 的知识、来源、授权与上下文投影边界。SQLite 是唯一游戏状态真相源；Prompt 只能消费本地授权后的投影，不能代替授权。

## 四层模型

- `WorldTruth` 是经过 `LOCAL_RULE`、`USER_ACCEPTANCE`、`DOMAIN_TRANSACTION` 或 `IMPORT` 授权的客观事实。AI 不是 Truth authority。
- `Claim` 是来自 Truth、Event 或 Actor 的主张，带置信度；无论其状态如何都不会自动变成 Truth。
- `Knowledge` 将一个 NPC 或 Player Character 与一个 Truth/Claim 目标绑定，记录 `KNOWN`、`SUSPECTED` 或 `BELIEVED` 状态、可见性、来源、学习时间、置信度和 revision。
- `Memory` 是特定 Actor 的主观摘要，只能引用该 Actor 当前 Knowledge 或同 Campaign Event；摘要本身不能创建 Truth。

`PlayerKnowledge` 使用 `actor_type = PLAYER_CHARACTER` 的独立 Knowledge 行，不从 NPC Knowledge、Shared 标记或世界事实列表推导。`SHARED` 表示该条记录可用于显式传播流程，不代表自动广播给所有 Actor。

## 持久化与来源完整性

schema 12 新增 `world_truths`、`knowledge_claims`、`actor_knowledge` 和 `knowledge_memories`。数据库约束与 Repository 同时执行以下规则：

- Actor、Truth、Claim、Event 和 Memory 来源必须属于同一 Campaign；不存在或跨 Campaign 的来源一律拒绝。
- Knowledge 的 Campaign、Actor 和目标身份不可更新；更新只能将 revision 精确增加 1。
- LEARN、UPDATE、FORGET 使用 expected revision 和 operation ID 幂等提交，并追加 `KNOWLEDGE_COMMITTED` event ledger；碰撞或任一步失败时整体回滚。
- 单 Actor 投影最多 256 条 Knowledge、128 条 Memory；Memory 摘要最多 4,000 字符，每类来源数组最多 128 项。
- Forget 删除当前授权行但保留 ledger 历史。重新学习应使用新的 Knowledge identity，不能复用已经进入审计历史的 revision 序列。

## 授权投影

投影入口必须同时匹配 Campaign、Actor type 和 Actor ID，再解析其显式 Truth/Claim 目标。秘密 Truth 只有在该 Actor 存在明确 Knowledge 授权时才能进入投影；完整 `WorldTruth` 集合、其他 NPC 的 Knowledge/Memory 和未授权秘密不得进入 Provider 输入。

`KNOWN Claim` 仍标记为 Claim；`SUSPECTED` 或 `BELIEVED` 不会改变目标种类。缺失目标、重复授权、跨 Actor Memory 来源或不一致数据均 fail closed。多 NPC Adventure 为每个参与者分别查询和投影，不能用一个 Actor 的集合填充其他参与者。

TypeScript NPC Dialogue 和 Windows 原生 NPC/Adventure 路径均优先消费 schema 12 的精确 Actor 投影。为兼容现有 V0.2 存档，若某 Actor 尚无新模型授权行，读取路径才回退到已经经过隔离验证的 `npc_knowledge` 投影；一旦存在新授权行，就不再拼接旧事实列表。Prompt 指令仍提醒模型不得越权，但安全边界由本地投影和提交事务保证。

## 迁移、恢复与限制

migration 12 将可归属的旧 `world_facts` 和 `npc_knowledge` 保守回填：非传闻进入 Truth，传闻与错误认知保持 Claim，旧 Known/Suspected/False Belief 分别映射为 `KNOWN`、`SUSPECTED`、`BELIEVED`，且不会暴露隐藏 veracity。来源无法满足 Actor/Campaign 完整性的损坏旧数据会拒绝迁移，不会伪造授权。

本地 schema 12 数据库支持关闭、重开和启动迁移。portable `.emtavern` 仍为 v2，当前尚不导出这四张新表；完整 V0.3 portable round-trip、历史 fixture、损坏/中断导入和跨语言格式升级统一由 M10-T05 完成。在此之前不得把本地重开测试表述为 portable archive 已覆盖。
