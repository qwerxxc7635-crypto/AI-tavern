# Ember Tavern v0.2 第一轮整改后可玩性报告

验证日期：2026-08-12

## 1. Verdict

**PLAYABLE BUT NEEDS POLISH — 8/10**

整改后的 production 路径已不再是只能完整走通的 Fake 垂直切片。DeepSeek 真实模型能够从设置页进入世界、车卡、酒馆、NPC、任务和冒险生成；玩家输入会改变结果；D20、关系和 SQLite 仍由本地规则掌控。短期真实 playtest 未发现死路或发布阻断问题。

## 4. Player, World and Tavern

- 世界：澜风境 / 雾屿走廊；中文生成，围绕黑色灯塔信标、雾海和潮汐谜团。
- 角色：Lin，盾卫；谨慎的灯塔侦察者，关注潮汐、遗迹与失踪守塔人。
- 特质：从六项语义相关候选中选择“潮汐之眼”“废墟学者”。
- 酒馆：沉星灯塔酒馆；老板阿澈；4 名 NPC、3 条带来源的传闻。
- 任务：生成两项；接受“潮痕下的封蜡”，HIGH 风险，预计 9～11 回合。

生成文本主体为自然简体中文。页面中出现的一句英文个人目标来自 playtest 时玩家自行输入，不是默认剧情或模型漏翻。

## 5. NPC Playtest

对同一 NPC 进行两轮真实对话：

1. 询问被水淹的门后有什么，回复结合该 NPC 的位置、知识与当前谜团，trust 0→1。
2. 玩家说明自己是 Lin，正在寻找失踪守塔人并持有潮汐罗盘；回复明确引用 Lin、守塔人和罗盘，trust 1→2、closeness 0→1。

退出 app、重开存档后，两轮消息顺序、NPC 关系和上下文完整恢复。NPC 基本身份与当前谜团一致，没有泄露未授权角色知识。

关系上限后的继续对话由自动化长回归覆盖：到达上限后不再提出越界增量，native 仍拒绝任何非法 patch。

## 6. Adventure and Player Agency

玩家自由输入：点亮守塔人的灯，用潮汐罗盘对照井壁痕迹，并在下井前先检查。

真实结果同时反馈了四个意图：

- 守塔灯被点亮并改变可见信息；
- 罗盘用于对照潮痕；
- 识别出高潮线与低潮线反序；
- 没有强行让玩家下井，而是把“先观察”转成知识检定。

这证明自由输入不只是被记录。生成的五条后续候选也分别围绕描摹潮痕、旧航海图、脚印凿痕、调整灯光和潮汐日志展开，不是通用模板。

Fake adapter 的根因也已修复：测试输出按 ACTION / DIALOGUE / OBSERVE 和玩家文本变化，用于离线回归时不再完全忽略选择。

## 7. D20 and Recovery

- 本地硬结果：raw 20 + knowledge modifier 2 = total 22，对 DC 11，SUCCESS。
- AI 只叙述既定结果，不能重投或改成败。
- 手工点击“跳过动画”成功；页面立即展示同一已保存结果，没有重新投骰。
- 结果叙事第一次因业务 patch 不兼容被安全拒绝；修复契约后重开，复用同一 20 点完成结算。
- 冒险 action 首次真实请求超时后，SQLite 中的 pending turn 保留；重开续跑同一行动，没有重复提交。
- 结算成功后 UI 回到可输入状态；针对从 RESOLVING 恢复的状态机回归已加入。

## 8. Save / Quit / Reopen

**VERIFIED**

- 模型默认设置保存在设备配置中，重开后仍选择 `deepseek-v4-flash`。
- 世界、角色、酒馆、NPC、任务、冒险、玩家行动和 D20 结果均从 SQLite 恢复。
- 两轮 NPC 历史和关系值恢复。
- pending action 与 locked roll 都能幂等续跑。
- API Key 不进入 `.emtavern` 存档或游戏 SQLite 内容。

## 10. DeepSeek Cache

**VERIFIED**

## 12. FIXED / VERIFIED / BLOCKED / REMAINING / NEW FINDINGS

### FIXED

- 模型设置与实际 Provider/Model 脱节。
- 七个桌面服务绕过统一编排。
- Fake 行动语义弱、默认生产故事英文模板化。
- NPC 重复、关系上限、危险确认和版本权限。
- 世界/NPC/任务/冒险/D20 schema 与 native 业务边界漂移。
- 恢复骰点后 UI 仍被锁定。

### VERIFIED

- DeepSeek 真实端到端生成、缓存、保存和重开。
- 两轮真实 NPC、自由冒险输入、D20 skip 与 locked-result recovery。
- 全量自动化与 macOS release build。

### BLOCKED

- Windows 实机游玩与安装生命周期：没有 Windows 主机。
- RustSec advisory 数据库：没有 `cargo-audit`。

### REMAINING

- 20+ 回合真实模型长期一致性、更多 NPC 声线差异和完整冒险结局质量需在第二轮独立长测。
- 真实网络延迟仍可能要求玩家使用安全重试/重开恢复。

### NEW FINDINGS

- 真实模型暴露的 timestamp、nullable、业务 patch 和恢复状态问题均已在本轮修复；没有剩余 P0/P1。
