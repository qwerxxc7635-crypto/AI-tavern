# Ember Tavern V0.3 Prompt Manager

## 1. 权限边界

Prompt Manager 只有两层，且不是等权合并：

1. Core Rule Prompt 由应用版本维护，固定包含 `SYSTEM_CONTRACT`、`GAME_RULES`、`OUTPUT_SCHEMA`、`PROMPT_PROFILE` 与 `STABLE_WORLD_TRUTHS`。
2. User Editable Prompt 只能作为最后一段 `USER_GUIDANCE` 附加叙事风格。

用户块不能覆盖前述段落，不能取得未装配的知识，不能改变输出 Schema，不能声明游戏状态已经提交。模型输出仍只是候选；本地结构校验、业务规则和 SQLite 事务继续决定事实。

## 2. 预设合同

设备级 `app_settings.prompt_manager_v1` 保存严格 schema version 1 快照：manager revision、活动 preset ID、最多 24 个 preset。每个 preset 有稳定 ID、显示名、递增 version 和最多 8 个有序用户块；块可禁用，也可限制到明确 AI task 闭集。运行时按保存顺序筛选启用且适用于当前 task 的块。

创建、更新、启用、恢复默认和导入均在单个 SQLite `BEGIN IMMEDIATE` 事务中重新读取并比较 manager revision。更新既有 preset 还必须匹配 preset version；竞争修改 fail closed。缺失设置解析为 revision 0 的默认模式，不隐式写库。合法快照可把活动 preset 设为 `null` 恢复默认 Core Prompt；若快照 JSON 通过数据库 JSON 约束但不符合 Prompt schema，专用安全恢复只允许在 Native 再次确认其仍然非法时删除该设置。无 revision 的调用不能重置并发出现的有效快照。

## 3. 导入、导出与秘密

可移植 bundle 固定为 `EMBER_PROMPT_PRESET` format version 1，只含单个用户 preset，不含 Core Rule Prompt、模型设置、Campaign 数据或凭据。导入作为新 ID 保存，不覆盖同名/同 ID preset；未知字段、未知 task、重复 ID、越界文本和错误 format/version 全部拒绝。

Native 导入和所有保存/导出复用存档安全扫描器。API Key、Authorization、Token、Credential 等秘密模式不能进入 `app_settings` 或 bundle；导入失败不会替换最后有效快照。

## 4. 运行时、缓存与修复

桌面编排在每次生成开始时并行读取模型选择和活动 preset，并将解析结果冻结到该次执行。Primary 失败后使用 Fallback 时不会重新读取 preset；结构修复也沿用原 preset。因此同一技术执行不会因设置并发变化而出现两个 Prompt 身份。

稳定 Prompt profile 升级为 version 3。`USER_GUIDANCE` 总是第六段：默认模式记录 inactive；活动模式记录 manager revision、preset ID/version 及有序块。任何 preset 保存或激活造成的 manager revision 变化都会改变稳定缓存前缀 hash；玩家动态输入仍不改变该稳定前缀。

## 5. UI 与迁移边界

“我的”页面提供只读 Core Rule 说明、活动 preset/恢复默认、preset version、块增删与排序、启用状态及 JSON 导入导出。UI 不展示 Core Prompt 编辑器，不提供安全/规则覆盖入口，也不复制 SillyTavern 的界面结构。

本切片只复用既有表单控件、页面结构和 Design Token，不展开 Legacy UI 重构。完整视觉迁移仍严格由 M10-T07 按视觉风格手册执行；Prompt Manager 后续迁移不得改变本文件的权限、版本、缓存或持久化合同。

## 6. 验收映射

- merge/order/core immutability：Prompt package 与桌面编排测试。
- version/import/export/secret/recovery：Rust Native 事务测试与 Windows 面板测试。
- cache revision/fallback freeze/repair：Prompt cache 与 Desktop Orchestrator 测试。
- persistence：关闭并重开同一 SQLite 后快照完全一致。
