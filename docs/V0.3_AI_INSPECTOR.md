# V0.3 AI Inspector

## Access and ownership

The AI Inspector is a read-only, session-local diagnostic projection. It is off in player mode and must be explicitly enabled from **My → AI Inspector**. The gateway exposes only `load(mode)`; it has no edit, retry, save, repository, or SQLite capability.

The current slice records the shared Windows desktop generation path. It reuses Generator lifecycle audit and Context Inspector metadata instead of creating another provider or persistence log. Inspector recording is best-effort: a projection failure cannot replace a generation result or its original error.

## Views

The latest snapshot includes:

- generation task, success/failure, and stable error code;
- provider display metadata and model;
- end-to-end latency;
- cache observation and shortened stable-prefix hash;
- input/output/total and provider cache token counters;
- Context manifest metadata;
- Prompt role/size projection;
- raw-output size and projection;
- parsed-result projection;
- validation issues, repair outcome, and full bounded Generator lifecycle.

Failed requests remain inspectable even when selection, prompt construction, provider output, parsing, or validation was not reached. Unreached fields are explicitly null/empty rather than fabricated.

## Redaction policy

Player mode returns no Inspector snapshot. Advanced mode displays metadata and structure but masks Prompt content, raw content, parsed scalar values, secret fields, and unauthorized world truth.

Developer mode can display bounded sanitized content, but still always hides:

- system/Core Prompt content;
- the stable prefix before `[TASK_INPUT]` when system messages were merged into a user message;
- API keys, bearer/Authorization values, cookies, passwords, credential references, secret/hidden fields, and World Truth fields;
- values beyond section, collection, lifecycle, validation-issue, or nesting limits.

The session retains at most 20 internally projected inspections. Display sections are capped at 8,000 characters, prompt messages at 32, lifecycle entries at 64, validation issues at 50, object fields at 128, array values at 64, and traversal depth at 12.

## Non-goals

M3-T04 does not add a database table, export Inspector data, expose the complete database, make Core Prompt editable, or allow generation replay. Persisted GenerationRecord remains the audit evidence used by game transactions; the Inspector is only a disposable view for diagnostics.
