## 3. P1 Closure

### AUDIT-001 — 模型设置未进入真实游戏生成路径

Severity：P1

Status：**FIXED / VERIFIED**

修复：

- 新增桌面统一入口 `DesktopAIOrchestrator`，每次请求从设备模型设置读取默认和明确授权的备用档案。
- 原生 `ai_generate` 按选中的精确 profile 从 SQLite 解析 Provider、模型、端点、能力和系统凭据引用；前端不能提交另一模型名绕过配置。
- 原生响应回传 profile/provider/preset/model 身份，编排器发现漂移会拒绝结果。
- 世界、角色特质、角色背景、酒馆、NPC roster、NPC 对话、任务、冒险计划、冒险回合、D20 结果叙事和结算全部迁移到同一入口。
- Fake Provider 只作为显式测试依赖；production singleton 使用 Tauri native adapter。

验证：

- 自动化证明保存的默认模型改变最终 Provider 请求模型，并拒绝伪造模型漂移。
- 真实 UI 生成记录的 `request_json.modelName` 均为 `deepseek-v4-flash`，覆盖 12 条已提交生成记录。
- 设置保存后创建世界、角色、酒馆、NPC、任务和冒险均实际使用该模型；退出重开后默认模型与游戏状态继续存在。

### AUDIT-002 — 桌面服务绕过统一 AI 编排器

Severity：P1

Status：**FIXED / VERIFIED**

修复：

- 七个桌面 service 统一调用 `DesktopAIEngine.execute`；只有 `TauriNativeAIProvider` 可以调用原生 `ai_generate`。
- Provider/模型路由、显式备用策略、Prompt、稳定前缀 hash、上下文检查、超时、结构校验、一次结构修复、错误标准化和缓存指标在统一层收敛。
- 原生边界再次校验设置身份并通过共享 OpenAI-compatible Provider adapter 发起 HTTP；凭据只在原生进程从系统凭据库读取。
- 缓存遥测写入改为 best-effort：遥测失败可观察，但不能把成功生成替换成失败。

验证：

- 静态生产路径检查确认没有桌面 service 直接调用 Provider 或原生命令。
- 编排器测试覆盖设置模型、显式 fallback、非可重试错误不切换、结构修复、缓存前缀和身份漂移。
- native mock HTTP 测试确认实际请求使用所选模型；错误映射覆盖认证、限流、超时、网络和服务错误。

## 5. DeepSeek Cache Verification

Status：**VERIFIED（真实 API）**

- 稳定 profile：`deepseek-v4-flash-prefix-v2`。
- 稳定段顺序固定为 System Contract、Game Rules、Output Schema、Prompt Profile、Stable World Truths；动态任务输入放在尾部。
- 同一 `GENERATE_WORLD` 前缀 hash `36a3f522e293…` 的两次真实请求：
  - 第一次：hit 0 / miss 1072。
  - 第二次：hit 1024 / miss 48，命中率 0.9552。
- 独立原生真实 Provider 测试还取得第二次请求 hit 128 / miss 114，并验证响应 JSON、模型身份和重开后的设置/指标持久化。
- 指标最多保存 200 条，只含 task、hit、miss、ratio、prefix hash 和时间；不保存 prompt、上下文、request id 或凭据。

这里区分了代码层稳定字节测试与真实 API 指标；没有用静态推断冒充真实命中。

## 6. New Findings During Remediation

以下问题均在本轮发现并修复：

1. **FIXED**：Rust RFC3339 微秒时间戳不满足前端毫秒 ISO contract；统一规范化后再进入 UI。
2. **FIXED**：世界、NPC roster、任务回合数、冒险 checkRequest、state patch 和 relationship nullable 在通用 schema 与 native 业务边界间存在漂移；约束已前移并增加回归。
3. **FIXED**：真实模型偶发首轮 JSON/业务不合规；统一层只允许同一模型进行一次结构修复，不做 test-only 硬编码。
4. **FIXED**：已提交冒险行动遇到超时后需要重开续跑；SQLite 保留同一 pending turn，恢复不重复提交。
5. **FIXED**：D20 结果叙事的 patch contract 过宽；只允许 native 可提交的 FACT/null-target/statement proposal。
6. **FIXED**：从 RESOLVING 状态恢复并成功结算后，UI 状态机未回到可输入态；成功路径现在显式 RESTORED，并有页面回归。
