M10-T06 自动性能门在 2026-08-24 的本地可重复 Fake Provider 证据上通过。该结论只覆盖同机本地调度、现有规则/序列化路径、真实 `GenerationQueue` 压力及代表性 SQLite/Unified Context 长存档增长，不外推为真实网络或模型 SLA。

- M1-T04 基线 commit：`589ef756c4df3b552a1b8c7cbf5b8da34c8793f5`
- Provider 证据：**FAKE**
- 真实 Provider：**NOT_RUN**
- 聚合：冷启动 3 批 + 同实例热运行 3 批，每批每任务 10 个样本；对每批 P95 再取中位数
- 总核心样本：300；不选单次最快值，不用最小值代表回归结论

核心 latency/queue 门槛为 `≤ max(M1 P95 × 3, M1 P95 + 5 ms)`。M1 Fake Provider 数据处于亚毫秒到低毫秒范围，5 ms 绝对余量用于隔离操作系统调度噪声；3 倍相对门仍会在越过噪声区后阻止显著增长。它不是可随结果调整的动态门槛，失败必须修复或通过 `docs/DECISIONS.md` 明确接受，禁止降低门槛隐藏回归。

## 3. Queue 与长期存档增长

真实 `GenerationQueue` 使用 concurrency=2、混合 P0/P1/P2 的 40 个同进程任务测量，queue wait P95 为 **2.000 ms**，门槛为 **50 ms**。

长期存档在当前 schema 32 SQLite 中写入同一 Campaign 的 100 与 1000 条 durable message。数据库大小采用 `page_count × page_size`，不使用可能受稀疏文件或 WAL 影响的表面文件大小：

- 100 回合：1,556,480 bytes
- 1000 回合：2,043,904 bytes
- 增量：**541.582 bytes/additional turn**
- 门槛：**≤ 4096 bytes/additional turn**

Unified Context 只投影固定 20 条 recent events、一个有界 memory summary、Constitution 和 current action，不读取全库或全量历史：

- 100 回合：377 estimated tokens
- 1000 回合：383 estimated tokens
- 增长：**1.016×**
- 门槛：**≤ 2048 tokens 且增长 ≤ 1.05×**

上述门同时约束持久化的线性增长和发给模型的有界投影；它不删除 durable history，也不以压缩 SQLite 真相换取 Context 数字。

## 4. Token 与 Cache

M1-T04 和当前 Fake Provider 都不报告 input/output token 或计费 prompt-cache usage。因此本次报告将两项标记为 **NOT_EVALUATED**，unknown 不转换为 0，也不使用进程内 prefix hash reuse 冒充 Provider cache hit。

自动门已固定真实 usage 的后续阈值：

- input tokens：每样本平均 **≤ 16,384**；
- Provider cache hit ratio：`hit / (hit + miss) ≥ 0.50`；
- hit/miss 必须来自 Provider usage；缺失 usage 不能得到 PASS。

真实 Provider 证据仍需用户单独授权并生成 `REAL/RUN` 报告，不得覆盖本 Fake 报告。

## 5. 自动门与复现

生成器拒绝覆盖已有 JSON/Markdown，避免静默替换证据：

```bash
pnpm performance:gate --output-dir /tmp/ember-v03-performance-gate
```

输出：

- `performance-regression.json`：固定字段的机器可读门禁结果，不包含 Prompt、messages、玩家文本、request ID 或凭据；
- `performance-regression.md`：M1 对比、阈值、观测值和解释；
- 进程退出码：任一已评估检查失败、证据身份不一致、冷/热批次不足或报告生成失败都会使命令失败。

定向测试覆盖多批 P95 中位数、冷/热身份、long-save、阈值失败、unknown usage、真实 token/cache 失败和 Markdown 报告生成。M10-T06 不修改 Rules Engine、AI Provider、业务状态机、SQLite schema 或存档格式。
